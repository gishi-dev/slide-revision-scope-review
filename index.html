公開デモ / サンプル資料室

資料の修正範囲を、要素IDで確かめる

コードで全件の差分を列挙 → AIの候補を照合 → 人が採否と理由を記録

すべて架空の資料・役割です。事前に用意したAIの出力例（区分候補）を再生しています（その場でAIを呼んでいません）。入力を変えた要素は再整理待ちになり、AIは再処理しません。
「許可内」「無変更」は候補です。人が原資料と照合して採用するまで、配布してよいという意味ではありません。配置は800×450の任意単位の設定値だけを比べ、実際の表示・読みやすさ・重なりは確かめていません。

1. 入力を確認する

資料を表として扱います。CSVの行を編集・追加して「入力を反映」を押してください。ページの順序は表で最初に現れる順です。同じページの行は連続させます。

修正前後の資料表と修正指示表を開く

allowed は text / x / y / width / height を | で区切ります。それ以外の属性は固定です。required は残す語句を | で区切り、unclear=true は判断基準が未指定の行です。指示の日本語はAIと人の参照用です。コードの判定条件も併せて編集してください。exact は指定本文、minX / maxX はxの範囲です。ID・ページ・種類は常に固定です。

2. 全件の差分と候補を照合する

この版は照合用に意図的に入れた候補です。AIの自然な失敗を観察した結果ではありません。

要素IDコードの差分・違反AIの区分候補と理由想定表との照合人の記録

3. 人が要素ごとに確定する

「差分を開く」で修正前後を確認してください。判断材料不足は質問が必要です。追加・削除のIDは対応の確認も必要です。保留・差し戻しが残る間は配布待ちです。

要素の「差分を開く」を選んでください。

4. 確認票・差し戻し依頼・履歴を書き出す

確認途中も未確定を明記して保存できます。資料表は上書きせず、依頼は送信しません。入力や判断はこのタブのメモリー内だけに保持されます。

最後に書き出したJSONを確認・コピーする

保存できない場合は、この内容をコピーしてJSONファイルとして保存できます。判断を更新したら、もう一度書き出してください。
